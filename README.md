# 🎀 Sanrio — Hello Kitty & Friends

Репозиторий проекта по курсу **«Разработка интернет-приложений»**.

- **Автор:** Рытикова Кирена
- **Группа:** ИБМ3-54Б
- **Тема проекта:** Сайт с товарами Hello Kitty & Sanrio

---

## 🌟 Лабораторные работы

### 🌸 Лабораторная работа №1: Главная страница Sanrio
- **Файл:** [`index.html`](index.html)
- **Описание:** Главная страница-лендинг в фирменном стиле Sanrio. Включает шапку с логотипом, верхнюю строку сервисов, навигационное меню, информационный баннер и промо-блок (Hero section) с кнопкой быстрого перехода к калькулятору.
- **Стили:** [`css/home.css`](css/home.css)

### 🎀 Лабораторная работа №2: Интерактивный калькулятор Hello Kitty
- **Файл:** [`calculator.html`](calculator.html)
- **Описание:** Стилизованный веб-калькулятор Sanrio с поддержкой:
  - Основных арифметических операций (`+`, `-`, `x`, `/`);
  - Очистки экрана (`C`);
  - Посимвольного удаления последнего знака (`⌫`);
  - Фирменной операции Sanrio — расчёт 5% кэшбэка (`💖`);
  - Ограничения длины выводимого числа и защиты от деления на ноль.
- **Скрипт:** [`js/script.js`](js/script.js)
- **Стили:** [`css/style.css`](css/style.css)

### 💖 Лабораторная работа №3: Каталог персонажей Sanrio (SPA на компонентах)
- **Файл:** [`lab3/index.html`](lab3/index.html)
- **Описание:** Одностраничное приложение (SPA) со структурированной компонентной архитектурой:
  - Каталог карточек персонажей Sanrio (Hello Kitty, Kuromi, Cinnamoroll, My Melody);
  - Фильтрация по категориям (*Все*, *Кошечки*, *Зайки*, *Собачки*);
  - Динамическое добавление и удаление карточек;
  - Детальная страница персонажа с описанием, хобби, днём рождения и цитатой-посланием;
  - Стилизация с использованием **Bootstrap 5** и кастомной палитры Sanrio.
- **Архитектура:**
  - `lab3/components/product-card/` — компонент карточки персонажа;
  - `lab3/components/product-detail/` — компонент детальной информации;
  - `lab3/pages/main/` — страница каталога с фильтрацией и управлением;
  - `lab3/pages/product/` — страница отдельного персонажа;
  - `lab3/mocks/characters.js` — моковые данные персонажей.

### 🐙 Страница проекта с переходом на GitHub
- **Файл:** [`github.html`](github.html)
- **Стили:** [`css/github.css`](css/github.css)
- **Описание:** Карточка проекта с прямой ссылкой на репозиторий [kiroioy/labs-kitty](https://github.com/kiroioy/labs-kitty).

## 🚀 Запуск проекта

1. **Клонирование репозитория:**
   ```bash
   git clone https://github.com/kiroioy/labs-kitty.git
   cd labs-kitty
   ```

2. **Просмотр страниц:**
   - Откройте `index.html` в браузере (или используйте расширение **Live Server** в VS Code).
   - Для полноценной работы модулей ЛР 3 рекомендуется запуск через локальный веб-сервер:
     ```bash
     npx serve .
     # или
     python -m http.server 8000
     ```

3. **(Опционально) Установка зависимостей для ЛР 3:**
   ```bash
   cd lab3
   npm install
   ```
   *(При запуске без локального `node_modules` Bootstrap автоматически подгружается через CDN).*
